# Cadastrar currículo
Eu como candidato gostaria de cadastrar meu currículo para vagas de trabalho.

## Regras de negócio

1. Será exibido um formulário com o título "Cadastre seu currículo".
	1. O design deve ser semelhante ao de um formulário do Google Forms. 
2. A primeira opção do formulário deve ser um botão "Anexar currículo".
	1. Os formatos aceitos são Word e PDF. Deve haver um texto explícativo sobre os formatos aceitos.
	2. Os arquivos não devem ultrapassar o limite de 10MB.
	3. Apenas um arquivo pode ser anexado.
3. Os demais campos serão "Nome completo", "Data de nascimento", "Email para contato", "Telefone para contato", "CEP de residência" e "Vagas desejadas".
	1. Todos os campos serão obrigatórios.
	2. "Nome completo": campo texto de até 100 caracteres.
	3. "Data de nascimento": campo de data com dia, mês e ano. Não deve aceitar datas posteriores à data atual.
	4. "Email para contato": campo de email (texto).
	5. "Telefone para contato": formato de telefone no padrão brasileiro.
	6. "CEP de residência": CEP é um código de logradouros brasileiros.
	7. "Vagas desejadas": Um lista com checkboxes com as vagas possíveis de se candidatar.
		1. As opções são: "Pedreiro", "Ajudante de pedreiro", "Eletricista", "Motorista", "Cozinheiro", "Marceneiro", "Técnico em segurança do trabalho", "Porteiro", "Outros".
		2. O candidato deve selecionar ao menos uma vaga e pode selecionar uma ou mais vagas. 
4. Ao final, deve haver os botões "Limpar" e "Salvar"
	1. "Salvar": salva os dados do formulário e persiste no banco de dados.
		1. Caso algum campo não esteja preenchido, exibe a mensagem "Preencha todos os campos"
		2. Caso a ação de salvar seja bem sucedida, exibe a mensagem "Salvo com sucesso", e limpa os campos.
		3. As mensagens devem ser exibidas em formatos de dialog.
	2. "Limpar": Reinicia o formulário com os campos limpos.
5. Esta será a tela de entrada no sistema. Será exibida na raiz da URL (/app).
