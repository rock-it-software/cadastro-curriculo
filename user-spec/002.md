# Filtrar currículos

Eu como recrutador gostaria de filtrar currículos para vaga de trabalho.

## Regras de negócio

1. Será exibido um formulário com o filtro "Buscar candidatos"
	1. O recrutador pode filtrar por "Vagas", "Cidade" e "UF".
		1. "Vagas": lista das vagas procuradas ("Pedreiro", "Ajudante de pedreiro", "Eletricista", "Motorista", "Cozinheiro", "Marceneiro", "Técnico em segurança do trabalho", "Porteiro", "Outros"). Somente uma vaga pode ser selecionada por vez.
		2. "Cidade": campo texto
		3. "UF": Dropdown com as 27 UFs brasileiras. Somente uma UF pode ser selecionada por vez.
	2. Apenas o campo "Vaga" é obrigatório. O recrutador pode selecionar somente este campo ou todos os campos. Nesse caso, os critérios se somam.
	3. A busca listagem é feita a cada alteração no filtro. No caso do campo "Cidade", o evento de busca será disparado ao clicar fora ou sair do campo.
2. Abaixo do filtro deve ser exibido um resumo com os filtros selecionados, com destaque para a vaga selecionada.
3. Abaixo do resumo, será exibida uma lista (tabela) de candidatos que atendam todos os critérios filtrados.
4. A lista deve ser ordenada por data de inclusão, do mais antigo para o mais recente.
5. Cada linha deve exibir "Nome completo", "Idade" (campo calculado a partir da data de nascimento), "Cidade", "UF" e por último um ícone na coluna "Baixar currículo" (ícone "Docs"). Ao clicar no ícone, deve baixar o currículo do candidato.
6. A lista deve ser paginada. Deve exibir 20 registros por padrão, mas o usuário pode mudar a quantidade de registros por página. Deve haver uma informação ao final da tabela com o total de registros totais na tabela.
7. O caminho para a tela é /app/recrutador. Não haverá autenticação.
